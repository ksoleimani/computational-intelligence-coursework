# Multilayer Perceptron (MLP)

## Objective

Implement a Multilayer Perceptron (MLP) neural network for handwritten digit classification using the MNIST dataset.

## Topics

- Neural Networks
- Multilayer Perceptron (MLP)
- MNIST Classification
- Categorical Cross-Entropy
- Adam Optimizer
- Batch Size
- Learning Rate
- MSE vs MAE Loss

## Libraries

- NumPy
- Pandas
- Matplotlib
- Keras

## Files

- MLP.ipynb
- mnist_train.zip
- mnist_test.zip

## Results

The project develops an MLP with two hidden layers for MNIST classification and evaluates its performance using different batch sizes and learning rates. The project also compares MSE and MAE loss functions using a single-neuron output model.
