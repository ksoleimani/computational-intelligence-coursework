# Clustering Algorithms

## Objective

Implement and compare unsupervised learning algorithms for identifying patterns and clusters in different datasets using Python and Scikit-learn.

## Topics

- K-Means Clustering
- DBSCAN Clustering
- Data Scaling
- Cluster Visualization
- Elbow Method
- Noise Detection
- Comparison of Clustering Algorithms

## Libraries

- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Files

- clustering.ipynb

## Results

The project compares K-Means and DBSCAN algorithms on different datasets, including spherical clusters, noisy data, and irregularly shaped clusters. The results demonstrate the advantages and limitations of each clustering method.
