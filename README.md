# Computational Intelligence Coursework

This repository contains programming assignments and projects completed as part of the **Computational Intelligence** course in the Department of Mechanical Engineering at **Amirkabir University of Technology (Tehran Polytechnic)**.

The coursework focuses on the practical implementation of machine learning algorithms using **Python** and **Scikit-learn**, covering the complete machine learning workflow including data preprocessing, model development, performance evaluation, and result analysis.

---

## Topics Covered

- Linear Regression
- Polynomial Regression
- Logistic Regression
- Decision Trees
- Random Forests
- Support Vector Machines (SVM)
- K-Nearest Neighbors (KNN)
- Artificial Neural Networks
- Clustering Algorithms
- Model Selection and Performance Evaluation
- Train / Validation / Test Splitting
- Cross Validation
- Bias-Variance Trade-off
- Underfitting and Overfitting
