# RNN and LSTM

## Objective

Implement and compare recurrent neural network architectures for time series prediction using Keras.

## Topics

- Time Series Prediction
- Simple RNN
- Sequence-to-Sequence Models
- LSTM
- GRU
- Conv1D + RNN
- Multi-Step Forecasting
- Model Evaluation

## Libraries

- NumPy
- Matplotlib
- Keras

## Files

- RNN_LSTM.ipynb

## Results

The project compares different recurrent neural network architectures for time series forecasting, including Simple RNN, LSTM, GRU, and Conv1D-RNN models. The models are evaluated using Mean Squared Error (MSE) for single-step and multi-step predictions.
