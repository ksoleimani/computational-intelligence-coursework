# Convolutional Neural Network (CNN)

## Objective

Implement and evaluate a Convolutional Neural Network (CNN) for handwritten digit classification using the MNIST dataset.

## Topics

- Image Filtering
- Convolution
- Sobel Filters
- CNN Architecture
- Max Pooling
- Feature Maps
- Model Training
- Hyperparameter Tuning

## Libraries

- NumPy
- Pandas
- Matplotlib
- Keras

## Files

- CNN.ipynb
- mnist_train.zip
- mnist_test.zip
- Bikesgray.png

## Results

The project develops a CNN for MNIST digit classification and investigates the effects of filter size, number of filters, and pooling size on model performance. The project also visualizes learned convolutional filters and their feature maps.
