# Classification Models for Diabetes Prediction

## Overview

This project explores supervised machine learning techniques for binary classification using a diabetes dataset. Several classification algorithms are implemented, compared, and evaluated using standard performance metrics.

---

## Objectives

- Perform exploratory data analysis (EDA)
- Train multiple classification models
- Compare classifier performance
- Analyze ROC and Precision-Recall curves
- Apply preprocessing pipelines
- Improve model performance through feature scaling and hyperparameter tuning

---

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Support Vector Machine (SVM)

---

## Techniques Used

- Train/Test Split
- Data Visualization
- Correlation Analysis
- Feature Scaling
- Scikit-learn Pipelines
- GridSearchCV
- Hyperparameter Optimization

---

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC Curve
- Area Under the ROC Curve (AUC)
- Precision-Recall Curve

---

## Tools and Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Results

The project compares the strengths and limitations of Logistic Regression, Decision Trees, and Support Vector Machines for diabetes prediction.

Model performance was evaluated using multiple metrics, including Accuracy, F1-score, and ROC-AUC, demonstrating the effect of preprocessing and hyperparameter tuning on classification performance.
