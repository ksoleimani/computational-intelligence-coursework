# Classification Models

## Objective

Develop and compare multiple machine learning classification models for diabetes prediction using Python and Scikit-learn.

## Topics

- Exploratory Data Analysis (EDA)
- Logistic Regression
- Decision Tree
- Support Vector Machine (SVM)
- Feature Scaling
- Hyperparameter Tuning
- Model Evaluation

## Libraries

- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Files

- classification.ipynb
- diabetes.csv

## Results

The project compares Logistic Regression, Decision Tree, and Support Vector Machine models using performance metrics such as Accuracy, Precision, Recall, F1-score, and ROC-AUC. The effect of feature scaling and hyperparameter tuning on model performance is also evaluated.
